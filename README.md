## 💡 1. 프로젝트 소개

### 📌 기획 배경 (Problem)
- **운동 중 UI 조작의 높은 피로도:** 웨이트 및 유산소 운동 중에는 땀, 스트랩/장갑 착용, 거친 호흡 등으로 인해 스마트폰 화면을 직접 터치하여 세트별 수치를 입력하는 과정에서 큰 번거로움과 기록 이탈이 발생합니다.
- **운동 흐름의 단절:** 세트마다 앱을 켜서 종목을 검색하고 중량·횟수를 일일이 기입하는 작업은 휴식 시간의 집중도를 떨어뜨리고 운동 흐름을 끊습니다.
- **웨이트·유산소 통합 분석 및 맞춤 피드백 부재:** 단순 수치 저장소를 넘어, 사용자의 누적 볼륨과 유산소 수행 데이터를 종합 분석하여 실시간 목표 제안 및 점진적 과부하 가이드를 제공하는 지능형 서비스가 부족합니다.

### 🎯 핵심 해결 방안 (Solution)
- **실시간 음성 기반 세트 등록 (Voice-to-Set):** 운동 세트 직후 말 한마디(*"벤치 80kg 10개 완료"*, *"천국의 계단 레벨 8 15분"*)로 종목과 수치를 인식하여 Spring AI를 통해 실시간 DB 적재 (Zero-UI 경험 제공).
- **통합 피트니스 분석 리포트 (Overload Analytics):** 누적 데이터를 바탕으로 주간 부위별 볼륨 증가율, 추정 1RM, 유산소 소모 시간/칼로리를 분석하여 개인 맞춤형 점진적 과부하 및 운동 밸런스 피드백을 제공합니다.
